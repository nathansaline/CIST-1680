CIST 1680 · FA2 Help, Pipes & Processes

Lab Objectives

MLO — Use help systems, redirection, pipes, and process-monitoring tools to inspect and control a Linux session.

Type each command yourself — command boxes are display-only (not copyable). Record results in the verification fields.

Lab Tasks

Part A — Help Systems

Task 1 – Built-in and Manual Help

Get short help for ls, then open the man page summary for grep.

Type these commands ls --help
man grep
whatis ps

Task 2 – type and which

Discover whether a name is a shell builtin or an external binary.

Type these commands type cd
type ls
which ls

Part B — Redirection & Pipes

Task 3 – Create a File with Redirection

Write three lines into a lab log using output redirection, then display it.

Type these commands echo "line one" > ~/lab-pipe.log
echo "line two" >> ~/lab-pipe.log
echo "ERROR: demo failure" >> ~/lab-pipe.log
cat ~/lab-pipe.log

Task 4 – Pipe and Filter

Filter the log for ERROR lines and count them.

Type these commands grep ERROR ~/lab-pipe.log
grep -c ERROR ~/lab-pipe.log

Task 5 – Redirect Errors

Run a command that fails and send stderr to a file (or /dev/null).

Type these commands ls /no/such/path 2> ~/lab-stderr.txt
cat ~/lab-stderr.txt

Part C — Process Monitoring

Task 6 – List Processes

Show your processes and a system-wide snapshot.

Type these commands ps
ps aux | head -5

Task 7 – Why Pipes and Processes Matter

In 2–3 sentences, explain why help systems, redirection/pipes, and process tools are essential for a help-desk or junior admin role.
