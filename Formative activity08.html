📋 Lab Objectives

MLO-3 / MLO-5 — Configure local static hostname resolution, resolver endpoints, and lookup order.

Part A

Task 1 – Examine Config Files

cat /etc/hosts
cat /etc/resolv.conf
grep hosts /etc/nsswitch.conf
Part A

Task 2 – nsswitch Order Meaning

What does the order of the hosts: line in nsswitch.conf tell the system to do? (1–2 sentences)

Part B

Task 3 – Add Static Entry

sudo cp /etc/hosts /etc/hosts.bak
echo '10.10.10.50 labserver.cis' | sudo tee -a /etc/hosts
cat /etc/hosts
Part B

Task 4 – Test Resolution

getent hosts labserver.cis
ping -c 2 labserver.cis
Part B

Task 5 – Restore Backup

sudo cp /etc/hosts.bak /etc/hosts
getent hosts labserver.cis || echo 'Entry successfully removed'
Part C

Task 6 – Global vs Local Nameserver

In 2–3 sentences, explain the difference between a global Internet nameserver and a local/subnetwork nameserver, and why a classroom might use a local TLD such as .cis.

Part C

Task 7 – External DNS Lookup

getent hosts google.com || host google.com
