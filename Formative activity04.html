Lab Tasks

Aligned Outcomes: MLO 1–5 — Command-line navigation, user identity, system information, filesystem hierarchy, and basic permissions.

Part A

Task 1 – Identity & System Snapshot

Run these commands and observe the output:

whoami
id
hostname
uname -a
uptime

Task 2 – History Practice

Display recent history and reuse the last command:

history | tail -10
!!

Part B

Task 3 – Directory Structure

Create the lab workspace and files:

pwd
mkdir -p ~/sysop-lab/docs ~/sysop-lab/scripts
cd ~/sysop-lab
pwd
touch docs/notes.txt scripts/test.sh
ls -la

Task 4 – Tree & Directory Stack

Explore structure and practice pushd/popd:

tree -L 2 ~/sysop-lab
pushd /tmp && pwd && popd && pwd

Part C

Task 5 – Permissions

Inspect and change permissions on the test script:

ls -l ~/sysop-lab/scripts/test.sh
chmod 755 ~/sysop-lab/scripts/test.sh
ls -l ~/sysop-lab/scripts/test.sh
stat ~/sysop-lab/scripts/test.sh

Task 6 – Root vs Regular User

In 2–3 sentences, explain the difference between a regular user and the root user, and why administrators prefer sudo over logging in directly as root.
