Task 6 – PID 1 & Default Target

Task 7 – CLI When GUI Fails

Part D

Task 8 – Match Automation Tools

Daily backup on a server that runs 24/7
Weekly cleanup on a laptop often powered off
Complex multi-step process with variables and error checking
Service that starts at boot and restarts on failure
