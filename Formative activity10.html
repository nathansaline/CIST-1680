Lab Objectives

Lab Tasks

MLO 1 — Variables, shebang, and executable permissions for Bash scripts.

Part A

Task 1 – Create hello.sh

In this simulator, create the script with a here-doc style write (no nano needed):

mkdir -p ~/scripts
cat > ~/scripts/hello.sh << 'EOF'
#!/bin/bash
echo "Hello from my first script!"
echo "Today is $(date)"
EOF
cat ~/scripts/hello.sh

Task 2 – Make Executable

ls -l ~/scripts/hello.sh
chmod u+x ~/scripts/hello.sh
ls -l ~/scripts/hello.sh

Task 3 – Run the Script

bash ~/scripts/hello.sh
~/scripts/hello.sh

Part B

Task 4 – checkuser.sh

cat > ~/scripts/checkuser.sh << 'EOF'
#!/bin/bash
USER_NAME=$(whoami)
echo "Current user is: $USER_NAME"
if [ "$USER_NAME" = "root" ]; then
echo "Warning: You are running as root!"
else
echo "You are a regular user. Safe to continue."
fi
EOF
chmod u+x ~/scripts/checkuser.sh
~/scripts/checkuser.sh

Task 5 – Shebang & chmod Explained

In 2–3 sentences, explain what the shebang does and why chmod u+x is required to run a script by name.

Part C

Task 6 – Exit Codes

ls /tmp
echo $?
ls /nonexistent_directory_12345
echo $?
