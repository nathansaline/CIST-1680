CIST 1680 · Formative Assessment 3

📋 Lab Objectives

Aligned Outcomes: MLO 10–12 — find/locate, tar/rsync/scp, package management (apt/dnf), ssh, and safe operational practices.

Part A

Task 1 – Searching with find & locate

Practice locating files by type and name:

find ~/sysop-lab -type f
find /var/log -name "*.log" -type f | head -6
locate sshd_config
Part A

Task 2 – Create & Inspect Archive

Compress the lab directory and verify contents:

tar -czvf ~/sysop-lab-backup.tar.gz -C ~ sysop-lab
tar -tzvf ~/sysop-lab-backup.tar.gz
ls -lh ~/sysop-lab-backup.tar.gz
Part B

Task 3 – Package Management Basics

Refresh indexes, search, and check package status:

sudo apt update
apt search tree | head -8
dpkg -l tree
Part B

Task 4 – Install & Use tree

Install the tree package and run it on your lab directory:

sudo apt install -y tree
tree ~/sysop-lab
Part C

Task 5 – SSH Presence Check

Confirm the SSH client and inspect config files:

which ssh
sshd -T 2>/dev/null | grep -E 'port |permitrootlogin'
ls /etc/ssh/
Part C

Task 6 – Key Auth & Updates

In 2–3 sentences, explain why administrators prefer key-based SSH authentication over passwords and why they always run apt update / dnf update before installing new packages.

Part C

Task 7 – Best Practices

List three best practices from the chapter that you will apply every time you work on a Linux system.

💡 Tip: The lab starts with a pre-built ~/sysop-lab directory. Run commands in the terminal, then fill the verification boxes. Type help for supported commands.
