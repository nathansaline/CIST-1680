📋 Lab Objectives

Focus — chmod, sticky bit, world-writable and SUID risk discovery.

Part A

Task 1 – Numeric & Symbolic chmod

mkdir -p ~/sec-lab && cd ~/sec-lab
echo "secret data" > report.txt
ls -l report.txt
chmod 600 report.txt
ls -l report.txt
chmod u+x,go-rwx report.txt
ls -l report.txt
Part A

Task 2 – Sticky Bit

ls -ld /tmp
mkdir shared && chmod 1777 shared
ls -ld shared
Part B

Task 3 – World-Writable Search

sudo find /home /tmp -type f -perm -002 -ls 2>/dev/null | head -8
sudo find /home /tmp -type d -perm -002 -ls 2>/dev/null | head -5
Part B

Task 4 – SUID / SGID Binaries

sudo find /usr -perm -4000 -ls 2>/dev/null | head -6
sudo find /usr -perm -2000 -ls 2>/dev/null | head -4
Part B

Task 5 – Why These Are Risks

In 2–3 sentences, explain why world-writable files and unnecessary SUID binaries are security risks.

Part C

Task 6 – Home Directory Audit

find ~ -type f -perm -002 2>/dev/null
find ~ -type d -perm -002 2>/dev/null
ls -la ~ | head -15
