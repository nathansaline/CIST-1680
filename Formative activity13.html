CIST 1680 · Sec FA1 Users & Privileges

Lab Objectives

Lab Tasks

Focus — /etc/passwd, shadow, group; user creation; sudo and least privilege.

Part A

Task 1 – Key User Files

head -8 /etc/passwd
sudo head -5 /etc/shadow
head -8 /etc/group

Task 2 – Your Identity

whoami
id
groups
sudo -l

Part B

Task 3 – Create Test User

sudo useradd -m -s /bin/bash -c "Security Lab User" seclab
sudo passwd seclab
grep seclab /etc/passwd
sudo grep seclab /etc/shadow
id seclab

Task 4 – Group Change & Cleanup

sudo usermod -aG sudo seclab
id seclab
sudo userdel -r seclab
id seclab 2>&1 || echo "User successfully removed"

Part C

Task 5 – sudo & Least Privilege

In 2–3 sentences, explain why admins prefer sudo over logging in as root, and what least privilege means here.

Task 6 – Safe Editing Tools

Why should you never edit /etc/passwd or /etc/sudoers with a normal text editor? What safer tools should you use?
