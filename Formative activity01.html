Aligned outcomes: command-line navigation, user identity, system information, filesystem hierarchy, and basic permissions. Part A · Identity, History & System Info

Task 1 — Run the identity and system information commands:

whoami
id
hostname
uname -a
uptime
VERIFY
Record your username, UID, hostname, kernel version, and system uptime.

Task 2 — Display history and practice the shortcut:

history | tail -10
!!
VERIFY
Note the last command in history and confirm !! repeated it.
Part B · Filesystem Navigation

Task 3 — Navigate and build a directory structure:

pwd
mkdir -p ~/sysop-lab/docs ~/sysop-lab/scripts
cd ~/sysop-lab
pwd
touch docs/notes.txt scripts/test.sh
ls -la
VERIFY
Paste the final ls -la output and your working directory.

Task 4 — Visualize the tree and practice the directory stack:

tree -L 2 ~/sysop-lab
pushd /tmp
pwd
popd
pwd
VERIFY
Sketch the tree output and list the two directories shown by pushd/popd.
Part C · Permissions Basics

Task 5 — Examine and change permissions on the test script:

ls -l ~/sysop-lab/scripts/test.sh
chmod 755 ~/sysop-lab/scripts/test.sh
ls -l ~/sysop-lab/scripts/test.sh
stat ~/sysop-lab/scripts/test.sh
VERIFY
Write the permission string before and after chmod 755, and note the Access line from stat.

Task 6 (written, not graded here) — In 2–3 sentences, explain the difference between a regular user and the root user, and why administrators prefer sudo over logging in directly as root. Jot notes below for yourself, then transfer your answer to the official worksheet.
