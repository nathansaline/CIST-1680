CIST 1680 · FA1 Architecture & Virtual Computing

Lab Objectives

CO-1 — Explain how computer hardware, software layers, and virtual machines work together to process data.

Type each command yourself in the terminal — command boxes below are display-only (not copyable). Then record what you see in the verification fields.

Lab Tasks

Part A — Information Processing Cycle

Task 1 – CPU Information

Show the first 20 lines of CPU information from lscpu.

Type this command lscpu | head -20

Task 2 – Memory Information

Display memory usage in human-readable units.

Type this command free -h

Task 3 – Information Processing Cycle

Match each action to one of: Input, Compute, Storage, or Output.

Part B — Registers, Cache, and RAM

Task 4 – Cache Levels

From lscpu, filter lines that mention Cache, Model name, or CPU(s).

Type this command lscpu | grep -E 'Cache|Model name|CPU\(s\)'

Task 5 – Registers, Cache & RAM

In 2–3 sentences, explain the difference between registers, cache, and RAM in terms of speed and size. Why does a computer need all three?

Part C — Virtual Computing

Task 6 – Virtualization Support

Check whether the CPU reports virtualization support (case-insensitive search).

Type this command lscpu | grep -i virtualization

Task 7 – VM Advantages

In 2–3 sentences, explain one classroom advantage and one industry advantage of using virtual machines.
